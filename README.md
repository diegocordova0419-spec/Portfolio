# Jose Diego Cordova — Portfolio

My personal portfolio site, built from scratch with HTML, CSS, and vanilla JavaScript. No frameworks, no build tools — just the fundamentals.

## Features

- Dark / light mode toggle (remembers your preference)
- Smooth scroll-triggered animations
- Six working projects with individual live pages and detailed project modals
- Responsive two-column project grid with a single-column mobile layout
- Direct email, GitHub, and LinkedIn contact links
- Task planner, expense tracker, and focus timer demos with responsive layouts

## Tech used

- HTML5
- CSS3 (custom properties, Grid, Flexbox, animations)
- Vanilla JavaScript (IntersectionObserver, localStorage)
- Google Fonts — Inter
